The current version of the LMFDB is {{ current }}.

LMFDB version numbers have the form {major}.{data}.{code} (for example 2.3.ba):

  • major is incremented by the managing editors for major milestones; the other two components reset when it is bumped.
  • data is incremented every time a batch of database tables is pushed to production. Each push archives the changed tables on Zenodo, so every table carries its own version of the form {major}.{data}, namely the LMFDB version at which it last changed; the data of any LMFDB version can be recovered from the corresponding Zenodo records.
  • code counts releases of the website code, written in the letter encoding used for elliptic curve isogeny classes (a, b, …, z, ba, bb, …). Each release corresponds to a commit in the LMFDB git repository.

Versions up to and including 1.2.1 predate this scheme.
